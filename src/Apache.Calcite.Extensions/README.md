# Apache.Calcite.Extensions

`Apache.Calcite.Extensions` contains .NET-friendly helper types used when integrating with Apache Calcite through IKVM.

It includes wrappers and utility abstractions that simplify working with Calcite Java-side configuration objects from
.NET code (for example, connection-property helpers).

## Install

```sh
dotnet add package Apache.Calcite.Extensions
```

## When to use this package

Use this package when building on top of the Calcite .NET projects and you need shared extension/helper types for
Calcite interop.
